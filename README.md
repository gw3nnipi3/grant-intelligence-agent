# Grant Intelligence Agent

An AI-powered agent designed to streamline grant discovery and research by helping users identify relevant funding opportunities and extract key application information.

## Features
- **Grant Discovery:** Find potential funding opportunities based on user requirements.
- **Intelligent Matching:** Identify grants aligned with specific projects or eligibility criteria.
- **Information Extraction:** Summarise deadlines, eligibility requirements, funding amounts, and application criteria.
- **Research Automation:** Reduce manual effort in searching and evaluating grant opportunities.
